# Yamaha A4000/A5000 editor: engineering notes (moved out of AGENTS.md)

The detailed section that used to live in `AGENTS.md`, kept verbatim apart from this heading (AGENTS.md now holds a short pointer with the rules that must not be broken). Written 2026-10-20.

The owner has an A4000 only. **Every measured protocol fact, the open-verification list and hardware tools: `dev_docs/a4000-editor-roadmap.md`; loading: `dev_docs/a4000-native-load-findings.md`. Read them before touching this.** Code: `core/yamaha_*`, `controller/yamaha_session.py`, `yamaha_transfers.py`, `ui/yamaha_*`.

**Wire rules (don't regress):**
- **No worker thread.** `YamahaSession` is event-driven on the GUI thread, ONE op at a time (a select is stateful) via a FIFO. **Never connect `controller.on_sysex_received` to `MidiManager.sysex_received` yourself** (already connected; a second delivers every message twice). A value is trusted only after a fresh announce naming the right object.
- A select gets NO reply. Bulk byte count is MSB-first and a dump is several blocks in one F0..F7: don't rewrite `parse_bulk_dump` to the manual's wording. `tests/fixtures/a4000/*.syx` are REAL captures: never regenerate them. `tools/a4000_discovery.py` is read-only; `a4000_write_verify.py` WRITES (throwaway units only, app closed).
- **Audio uses the native wave dump ("WD"), not SDS** (SDS stalls after a stereo recording and can't reach the right channel). **A bulk dump can't be aborted**: a cancelled wave makes the session DRAIN (up to ~70 s). `is_sds_transfer_busy()` is what the session waits out; never make it wait on `is_transfer_busy()` (which also counts a Yamaha receive).
- **Bulk Protect ON makes the unit cancel SDS sends and silently ignore edits.** Check it first when something "does nothing".
- Manual deviations: sample `P2=66` (AEG sustain) is `P3=2`; wave/loop addresses are coupled; `sampling_frequency`/`wave_length`/`wave_end_address` are ignored on a BUILT-IN sample; every edit sets the object's "edited" flag.

**Writes:** `write_parameter(row, value, object_name, cb, slot=)`, one parameter per op. The first write per object per session dumps it and saves a `.syx` backup (`~/.akaisds/a4000_backups`): **no backup, no write**. Sent only after an announce names the right object; a read-back must equal the value. `WriteCoordinator` throttles (150 ms), shows the one-time warning, re-reads when writes settle. Restore = guarded writes of differing rows (NOT a bulk load), snapshot first. Assign/Remove is `change_link`. The window refuses to close or refresh under a write.

**Edits and slices make NEW samples; nothing is overwritten** (no delete/overwrite over MIDI; a re-sent name resets ALL parameters). Copies are `<name> EDIT` (working copy) or `TRIM`/`REV`/`FADE`/`NORM`/`FILT`/`STR`/`PITCH` (a dialog's own "Send as New Sample"), 16 chars, a clash adds ` 2`, via native bulk load (`yamaha_edit.params_for_copy`). "Also fill a program with the slices" ASSIGNS slices to an EMPTY program from key 36 up, max 92.

**Native loading** (`core/yamaha_load.py`, `YamahaTransfers.send_file_queue`): wave dump(s) + one SP, paced by wire time + `send_gap_ms`, then VERIFIED; never overwrites (a clash gets ` 2`); wave names are random `SMP nnnnnn` (a wave under an existing wave's name IS overwritten in place). **Silent unit after bulk loads:** it can show "MIDI Bulk Received" and answer nothing until a person presses OK (Knob 5); the app copes (`_recover_silent_link`) and asks before assigning a sample this run loaded (`midi_loaded_names`).

**UI:** cards in aligned pairs are pinned equal (`equalize_card_heights`); the stereo waveform is ONE display (two views via `set_stack_position`, zoom on the top view is followed); sample list rows have NO item text (name in `Qt.UserRole`; `tab.sample_names()`); **no per-sample durations or memory bar** (each needed a slow scan); **long operations freeze navigation** (`_apply_lock`/`_is_busy`), deliberately not `main_tabs.setEnabled(False)`. Markers: `core/yamaha_markers.py` models the unit's FOUR addresses and orders writes (it silently ignores one breaking start <= loop_start <= loop_end <= end); never write the view's loop markers back wholesale. **Detect Pitch** shares Detect Root Note's engine (guesses, one line each: `FINE_TUNE_STEPS_PER_CENT = 1.0`, the sign); **A5000 gating** is unverified. Tests: replies over time use `rig.midi.paced = True`; never swap a test object's `__class__` (intermittent segfault); never let a bulk string replace touch more than one place in `yamaha_session.py`.
